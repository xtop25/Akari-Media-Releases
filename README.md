# Akari Media — скачать для Windows

Медиаплеер и каталог аниме для Windows.

## Установка

1. Откройте [последний релиз](https://github.com/xtop25/Akari-Media-Releases/releases/latest).
2. Скачайте файл `Akari-Media-Setup-*.exe` и запустите его.
3. Следуйте инструкциям установщика. Программе нужен Microsoft Edge WebView2; установщик может предложить его загрузить.

Установщик не подписан цифровым сертификатом, поэтому Windows может показать предупреждение о неизвестном издателе. Проверяйте, что файл скачан именно из этого репозитория; SHA-256 будет указан в описании релиза.

Каталог аниме работает через Shikimori. Встроенный плеер использует AniLibria: не у каждого аниме доступны все серии или любое видео. Ссылки AniList на внешние сервисы и серии открываются в браузере; доступность, язык и необходимость подписки зависят от сервиса и региона.

[Исходный код Akari Media](https://github.com/xtop25/Akari-Media)
